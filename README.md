# Bedrock Diamond Finder

Web app experimental para testar pontos de mineração no Minecraft Bedrock.

## Arquivos
- `index.html`
- `style.css`
- `script.js`

## Aviso
A lógica atual é experimental e **não garante** diamantes reais no Bedrock 26. O objetivo é testar pontos de forma determinística e registrar acertos/erros até substituir a lógica por um gerador Bedrock validado.

## Rodar
Basta abrir `index.html` em um navegador ou publicar com GitHub Pages.
